# AD-Alterome 专家评阅包

本包包含基因、表型和假说三类问题，每类 5 题，共 **15 题、45 份匿名回答**；每道问题的 3 份回答相邻，题内顺序已随机固定。采用 **三维 1–4 分**，三项分数均已填写即计为完成；评阅备注选填。尚未评阅的项目初始均未评分。

## 启动与保存

先解压完整评分包，再启动。需要 Python 3，无需安装第三方依赖。

- **macOS**：双击 `start.command`。
- **Windows**：双击 `start.bat`。
- **Linux**：在本文件夹运行 `sh start.sh`。

启动程序会选择可用本机端口并自动打开浏览器；若浏览器没有打开，请复制终端显示的 `http://127.0.0.1:端口/` 地址。保留终端窗口，评分结束后确认页面显示已保存，再按 `Ctrl+C` 关闭服务。首次在 macOS 运行时，若系统阻止打开下载的脚本，可在终端进入本文件夹后运行 `sh start.sh`。

页面修改会自动写入本包的 `ratings/专家编号.json`。默认编号为 `E01`，不同编号分别保存；切换编号会切换整套评分记录。再次启动时使用同一编号即可继续评分。请把评分包放在可写的位置，不要直接在压缩文件中运行。

本次量表版本为 `three-dim-1to4-20261015-v2`。从四维旧版升级时，由组织者先完整归档旧评分，再按材料内容核验迁移：只有未改动页面的前三项分数与备注可保留；更换回答或证据的页面须重新评分。旧推理评分与严重幻觉标记保留在历史归档，不进入本版评分或导出。请勿自行覆盖旧评分文件或仅修改版本号；服务不会自动改写不匹配的记录。更新后须重新启动本机服务并刷新页面。

“已保存”表示本机服务已确认写入磁盘；保存失败时应保留页面，不要立即关闭。浏览器草稿备份用于保留未完成的修改，磁盘记录是正式保存来源。若两个页面同时修改同一条记录，页面会提示冲突；先核对现有记录，再选择载入或以当前草稿重试。修改不同回答页不会覆盖其他页。

页面提供 JSON/CSV 导出，可用于提交或额外备份；正式评分文件也可从 `ratings/` 文件夹取得。请按组织者约定提交自己的评分文件。直接双击 `index.html` 只能作浏览器预览，**不会自动写入 `ratings/`**；此模式下需导出保存。

## 阅读与评分

每页依次展示双语问题、英文回答及其逐段中文译文、引用来源材料和评分区。浅黄色中文用于辅助阅读；如译文与英文存在理解差异，以英文原回答为准。点击回答中的引用可定位相应来源卡片。引用来源卡片仅提供核查材料，不表示已经判定该来源支持回答。

评分规则可在浮动窗口中查看、拖动与固定。三维分别为：

- **事实与来源准确性（证据本身）**：来源、PMID、题名、原句，以及基因、干预对象、模型背景是否准确。
- **证据支持与可追溯性（证据-回答关联）**：关键论断是否有可定位的证据，且方向、条件和适用模型对应。
- **问题回应与覆盖度（回答本身）**：是否直接回应问题，覆盖必要且正确的核心内容。

三维独立判断，同一错误不自动连扣；缺少引用主要影响证据支持，不直接证明事实虚构。无法核实时可暂留未评并备注。页面允许未完成就翻页，三维分数有效即计入完成数，不要求填写备注。

“参考得分点”窗口提供当前问题的评阅参考要点，可与回答及引用材料对照。同一问题的 3 份回答使用相同参考；要点允许等效表述，不代替逐条核查，也不会自动为回答打分。

## 本地运行选项

```sh
python3 server.py --port 8765
python3 server.py --no-open
python3 server.py --no-open --ratings-dir "/absolute/path/to/ratings"
```

`--port 0`（默认）自动选择可用端口；`--ratings-dir` 可隔离演练或测试数据。服务只监听 `127.0.0.1`，静态访问仅开放已知页面资源；原始实验资料、分组映射和评分文件目录均不作为网页静态资源发布。仅支持本机使用。

若已有评分 JSON 损坏或不属于当前题集，服务会报告错误并保留原件，不会把它当作空记录覆盖。请先备份相关文件，再交由组织者处理。程序写入时使用临时文件、磁盘同步和原子替换；保存版本冲突返回错误，不会静默覆盖。

本包评分仅包含三维与备注，不自动生成或修改专家分数。旧版量表和历史评分由组织者归档。
